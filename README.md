# RTportfolio
Coding portfolio

Project 1 - Name Generator
Summary: This program has the user choose between dog or cat and then answer a series of questions about preferred size and color to reveal the breed that aligns.
Key features: 
- There are 8 total outcomes
- Each answer determines your choices

Project 2 - MadLibs 
Summary: This program has the user input an adjective, location, animal, body part, and verb to fill in the blanks of an unfinished story.
Key features:
- displays full story at the end
- If the guidelines are not followed the story will not make sense

Project 3 - Leap Year
Summary: This program is defined by the rules of a leap year (if a year is divisible by 4, it is a leap year However if that year is also divisible by 100, it is not, and if it is divisible by 400 it is a leap year). Then the program calculates if the inputted parameters are leap years. 
Key features:
- The program prints "true" or "false"

Project 4 - Headline
Summary: This program has the user enter a noun, possesive pronoun, and place (not always in this order) to fill in the blanks of an unfisnished headline. 
Key features:
- The inputs should be atypical because it is supposed to be a shocking news headline
- displays full story at the end

Project 5 - Conditional Challenges
Summary: This program has the user input answers and fill in parameters to find if they are eligible to vote, find the largest number of 3, and calculate a letter grade. 
Key features:
- You have to be 18 or older and a US citizen to be eligible to vote
- the 3 numbers are labeled A-C
- If the value is below 0 your letter grade is calculated as invalid
